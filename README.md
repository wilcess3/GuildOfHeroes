Тема проекта: Продуктовый магазин

Главный класс: Product

Почему этот объект нужен программе:


Какие данные хранит объект:

- Name
- Price
- Quantity
- Category

Какие значения задаются через конструктор:
* Name
* Category
* Price

Какие значения можно задавать автоматически:
* Quantity

Какое значение я решил задавать автоматически и почему?
Я добавила поле **IsAvaliable** (В наличии ли товар???). У него есть значение true, если товар сейчас в наличии. Я выбрала именно это, потому что логично, что только что добавленный товар 100% будет в наличии. Если бы я каждый раз передавала это значение вручную в скобках **(new Product (.., true))**, это засоряло бы код
